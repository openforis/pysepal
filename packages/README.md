# packages

`pysepal-maplibre/` mirrors [dfguerrerom/pysepal-maplibre](https://github.com/dfguerrerom/pysepal-maplibre), the map widget pysepal depends on, so pysepal builds and tests against it until that package is on PyPI. Do not edit it here: change the repository, then mirror one of its commits with `python scripts/sync_maplibre.py PATH_TO_PYSEPAL_MAPLIBRE` and commit the result.
