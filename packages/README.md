# packages

`mapframe/` mirrors [dfguerrerom/mapframe](https://github.com/dfguerrerom/mapframe), the map widget pysepal depends on, so pysepal builds and tests against it until that package is on PyPI. Do not edit it here: change the repository, then mirror one of its commits with `python scripts/sync_mapframe.py PATH_TO_MAPFRAME` and commit the result.
